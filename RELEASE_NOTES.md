# GeoVibe v1.0.0 — Primera fase funcional

Esta versión presenta la primera fase funcional de GeoVibe: un dashboard de monitoreo de vibraciones con protocolo de alarma, orientación offline, comunicación de estado y visualización de alertas en Red EEW.

| Componente | Incluido en esta versión |
|---|---|
| Monitor | Lecturas de aceleración en tiempo real, umbral configurable y confirmación sostenida de eventos. |
| Protocolo de alerta | Aviso visual, tono prioritario, vibración, silenciado manual y apagado automático a los 10 segundos. |
| Seguridad | Estoy a Salvo con WhatsApp, Messenger/Facebook o SMS y ubicación aproximada cuando está disponible. |
| Consulta offline | Guía de Supervivencia con acciones antes, durante y después de un sismo. |
| Red EEW | Mapa de El Salvador, epicentros seleccionables, filtros departamentales y alertas de evacuación. |
| Diagnóstico | Estado de batería, ahorro de energía y frescura del monitor. |

> La APK se distribuye como paquete de depuración para Android. Para que las funciones dependientes del sistema puedan operar, concede los permisos de notificaciones y ubicación y revisa la configuración de Alertas críticas dentro de la aplicación. La disponibilidad de WhatsApp, Facebook/Messenger, SMS, No Molestar y pantalla bloqueada depende de las aplicaciones instaladas y de las políticas Android del dispositivo.
